## 🌟 প্রধান সুবিধাসমূহ (Key Features)

### 1. 💱 স্মার্ট কারেন্সি কনভার্টার (Smart Currency Converter)
- **স্মার্ট অটো-ফরম্যাটিং ইনপুট (Smart Number Input):** টাইপ করার সাথে সাথে স্বয়ংক্রিয়ভাবে কমা (`,`) ও সঠিক দশমিক ফরম্যাটে কারেন্সি সংখ্যা বিন্যস্ত হয় (যেমন `1000` টাইপ করলে `1,000` হয়ে যায়)।
- **দ্রুত প্রিসেট বাটন:** `100`, `500`, `1,000`, `5,000`, `10,000` এক ক্লিকেই ইনপুট করার সুবিধা।
- **তাত্ক্ষণিক অদলবদল (Visual Swap Button):** 'From' এবং 'To' কারেন্সির মাঝে ভিজ্যুয়াল সুইচার বাটন যা ক্লিক করলে ১৮০ ডিগ্রি ঘূর্ণন অ্যানিমেশনসহ তাৎক্ষণিক কারেন্সি অদলবদল হয়।

### 2. 🔍 রিয়েল-টাইম সার্চ ড্রপডাউন (Real-Time Search Dropdown)
- **দেশ বা মুদ্রার নাম অনুসারে অনুসন্ধান:** যে কোনো দেশের নাম (যেমন: *Bangladesh, United States, Germany, Japan*), মুদ্রার নাম (যেমন: *Taka, Dollar, Euro, Yen, Pound*), অথবা দেশের কোড (যেমন: *BD, US, DE, JP, GB*) লিখে দ্রুত ফিল্টার করা যায়।
- **ম্যাচ ইন্ডিকেটর ব্যাজ:** দেশ বা মুদ্রার সাথে মিল পাওয়া তথ্য তাৎক্ষণিকভাবে হাইলাইট করে প্রদর্শিত হয়।
- **কিবোর্ড নেভিগেশন:** মাউসের পাশাপাশি কীবোর্ডের `Arrow` কি এবং `Enter` চেপে দ্রুত সিলেক্ট করা যায়।

### 3. 📈 লাইভ রেটস টেবিল ও ৭ দিনের ট্রেন্ড স্পার্কলাইন (Live Rates with 7-Day Sparklines)
- **৭ দিনের ট্রেন্ড চার্ট (7D Sparkline):** প্রতিটি প্রধান মুদ্রার বিগত ৭ দিনের ওঠানামার সুন্দর মিনি চার্ট।
- **অন/অফ টগল (Show/Hide Trends):** ব্যবহারকারীর পছন্দ অনুযায়ী স্পার্কলাইন ট্রেন্ড কলাম দৃশ্যমান বা আড়াল করার ডেডিকেটেড টগল বাটন।
- **ইনভার্স ক্যালকুলেশন:** বিপরীত অনুপাত (Inverse Rate) দেখার সুবিধা।

### 4. 💸 আন্তর্জাতিক মানি ট্রান্সফার ফ্লো (International Money Transfer)
- **মাল্টি-স্টেপ ট্রান্সফার উইজার্ড:** কোট তৈরি, প্রাপকের তথ্য (IBAN / অ্যাকাউন্ট), পেমেন্ট মেথড বাছাই এবং নিরাপদ কনফার্মেশন।
- **রিসিট সেভ ও ড্রাইভে ব্যাকআপ:** সম্পন্ন ট্রান্সফারের রিসিট সরাসরি ডাউনলোড এবং Google Drive-এ স্বয়ংক্রিয়ভাবে সংরক্ষণ করার সুবিধা।

### 5. 🔔 রেট অ্যালার্ট ও ইন্টারঅ্যাক্টিভ চার্টস (Rate Alerts & FX Charts)
- **কাস্টম রেট অ্যালার্ট:** মুদ্রা নির্দিষ্ট লক্ষ্যমাত্রায় পৌঁছালে নোটিফিকেশনের অ্যালার্ট তৈরি।
- **ঐতিহাসিক চার্ট:** ১ দিন, ১ সপ্তাহ, ১ মাস, ১ বছর ও ৫ বছরের ইন্টারঅ্যাক্টিভ চার্ট ডাটা।

### 6. 📲 মোবাইল ডিভাইস সার্বক্ষণিক সক্রিয়তা ও রিয়েল-টাইম নোটিফিকেশন (Mobile Always-Active PWA & Notifications)
- **ব্যাকগ্রাউন্ড সার্ভিস ওয়ার্কার (Background Active Service):** মোবাইল ইন্টারনেটের সাথে যুক্ত থাকা অবস্থায় অ্যাপটি সার্বক্ষণিক সক্রিয় থাকে এবং লাইভ রেট সিঙ্ক করে।
- **মিনিমাইজড মোডে পুশ নোটিফিকেশন:** অ্যাপ মিনিমাইজ করে রাখলেও বা স্ক্রিন লক থাকলেও সিস্টেম নোটিফিকেশন ও ভাইব্রেশন পাঠিয়ে আপডেট জানায়।
- **তাত্ক্ষণিক ও ৫ সেকেন্ড মিনিমাইজ টেস্ট বাটন:** ব্যবহারকারী সরাসরি টেস্ট করে নিশ্চিত হতে পারেন যে মিনিমাইজ অবস্থায় নোটিফিকেশন কাজ করছে কিনা।
- **PWA মোবাইল ইনস্টলেশন:** অ্যান্ড্রয়েড ও আইওএস (iPhone/iPad) ডিভাইসে সরাসরি হোমস্ক্রিনে ইনস্টল করার সুবিধা।
- **স্ক্রিন জাগ্রত মোড (Screen Wake Lock):** এক্সচেঞ্জ রেট মনিটর করার সময় ডিসপ্লে স্বয়ংক্রিয়ভাবে স্লিপ হওয়া বন্ধ রাখার অপশন।

### 7. 📤 বিভিন্ন মিডিয়া প্ল্যাটফর্মে শেয়ারিং ও কিউআর কোড (Multi-Platform Social Sharing & QR Code)
- **পপুলার মেসেঞ্জার ও সোশ্যাল মিডিয়া:** WhatsApp, Facebook, Messenger, Telegram, X (Twitter), LinkedIn, Email এবং SMS-এ সরাসরি ১-ক্লিকেই শেয়ার করার সুবিধা।
- **লাইভ এক্সচেঞ্জ রেট সহ শেয়ার:** ব্যবহারকারী যে কোনো নির্দিষ্ট কারেন্সি ক্যালকুলেশন (যেমন: ১,০০০ USD = ১২১,৫০০ BDT) সরাসরি রেট হিসেব সহ শেয়ার করতে পারেন।
- **মোবাইল নেটিভ শেয়ার শিট (Web Share API):** মোবাইল ব্রাউজারে থাকলে ফোনের সব ইনস্টল করা অ্যাপে একবারে শেয়ার করার নেটিভ শিট চালু হয়।
- **ডায়নামিক কিউআর কোড (QR Code Generator):** কম্পিউটার স্ক্রিন থেকে মোবাইলের ক্যামেরা দিয়ে স্ক্যান করে সাথে সাথে অ্যাপটি ওপেন ও ইনস্টল করার জন্য হাই-রেজোলিউশন কিউআর কোড এবং ইমেজ ডাউনলোড অপশন।
- **ওয়ান-ক্লিক কপি লিংক:** যে কোনো জায়গায় পেস্ট করার জন্য ক্লিপবোর্ডে লিংক কপি করার বোতাম।

### 8. 🛡️ বায়োমেট্রিক অথেন্টিকেশন (Touch ID / Face ID / WebAuthn Passkeys)
- **নেটিভ ডিভাইস বায়োমেট্রিক সাপোর্ট:** আইওএস (iPhone/iPad-এ Face ID / Touch ID), ম্যাকবুক (Touch ID), অ্যান্ড্রয়েড (Fingerprint / Face Unlock) ও উইন্ডোজ (Windows Hello)-এর জন্য আধুনিক W3C WebAuthn FIDO2 ইন্টিগ্রেশন।
- **ওয়ান-টাচ কুইক সাইন-ইন:** পাসওয়ার্ড মুখস্থ না রেখে ডিভাইসের ফিঙ্গারপ্রিন্ট সেন্সর ছুঁয়ে বা ফেস স্ক্যান করে তাৎক্ষণিক লগইন করার সুবিধা।
- **রেজিস্ট্রেশনে বায়োমেট্রিক এনরোলমেন্ট:** নতুন অ্যাকাউন্ট তৈরির সময় ১-ক্লিকে নিজের ডিভাইসকে পাসকি হিসেবে যুক্ত করার অপশন।
- **রিয়েল-টাইম স্ক্যানিং ইন্টারফেস ও অ্যানিমেশন:** ইন্টারঅ্যাকটিভ পালসিং রাডার স্ক্যানার অ্যানিমেশন, অ্যাকোস্টিক/হ্যাপটিক ভাইব্রেশন ফিডব্যাক ও ভেরিফাইড স্ট্যাটাস।
- **ফলব্যাক নিরাপত্তা:** বায়োমেট্রিক ক্যানসেল বা অনুপলব্ধ হলে স্ট্যান্ডার্ড পাসওয়ার্ড দিয়ে সাইন ইন করার নিরবচ্ছিন্ন সুবিধা।

## 🚀 ইনস্টলেশন ও রান করার নিয়ম (Getting Started)

### পূর্বশর্ত (Prerequisites)
- **Node.js**: v18.0.0 বা তার পরবর্তী সংস্করণ
- **npm**: v9.0.0 বা তার পরবর্তী সংস্করণ

### ধাপ ১: ডিপেন্ডেন্সি ইনস্টল করুন (Install Dependencies)
```bash
npm install
```

### ধাপ ২: ডেভেলপমেন্ট সার্ভার চালু করুন (Start Dev Server)
```bash
npm run dev
```
সার্ভার চালু হলে ব্রাউজারে `http://localhost:3000` এ ভিজিট করুন।

### ধাপ ৩: প্রোডাকশন বিল্ড তৈরি করুন (Build for Production)
```bash
npm run build
```

### ধাপ ৪: টাইপ ও সিনট্যাক্স যাচাই করুন (Lint / Type Check)
```bash
npm run lint
```

## 💡 ব্যবহারের নিয়মাবলী (Usage Guide)

1. **টাকা কনভার্ট করতে:**
   - ড্রপডাউনে ক্লিক করে দেশ (যেমন `Bangladesh`) বা মুদ্রার নাম (`BDT`) টাইপ করে সিলেক্ট করুন।
   - অ্যামাউন্ট বক্সে কাঙ্ক্ষিত অংক লিখুন; সিস্টেম নিজে থেকেই কমা ফরম্যাট করবে।
   - মাঝের **Swap** বাটনে ক্লিক করে মুহূর্তেই কারেন্সি অদলবদল করুন।

2. **৭ দিনের ট্রেন্ড দেখতে/লুকাতে:**
   - **Live exchange rates** সেকশনে যান।
   - উপরের টুলবারের **7D Trends (On/Off)** বাটনে ক্লিক করে ৭ দিনের ট্রেন্ড চার্ট নিয়ন্ত্রণ করুন।

3. **টাকা পাঠাতে (Send Money):**
   - **Send** ট্যাবে গিয়ে প্রাপকের নাম, ইমেইল ও অ্যাকাউন্ট নম্বর প্রদান করে নিশ্চিত করুন।
   - সফল হলে রিসিট ডাউনলোড করতে পারবেন অথবা গুগল ড্রাইভে ক্লাউড কপি সেভ করতে পারবেন।
